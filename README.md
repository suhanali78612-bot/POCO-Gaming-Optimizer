# POCO Gaming Optimizer (Root-free)

Android Studio project for a black-and-red gaming dashboard.

## Features
- Available / total RAM readout
- Free / total internal storage readout
- Battery percentage and battery temperature
- Free Fire / Free Fire MAX launch shortcut (if installed)
- Shortcuts to Android app, storage, battery, and display settings
- No root, ads, account, network permission, or risky cleaner claims

## Build APK
1. Open this folder in Android Studio (with Android SDK 35 installed).
2. Allow Gradle sync and install suggested dependencies.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Find APK in `app/build/outputs/apk/debug/app-debug.apk`.

This is source code, not a compiled APK. It does not automatically boost FPS or clear other apps' caches.
